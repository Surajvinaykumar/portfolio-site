AI-Powered Job Search Automation

Description

This project is an AI powered job search assistant that I designed to reduce the time and effort spent on finding and acting on relevant roles. Every morning at 9 AM, the workflow runs automatically, pulls fresh and targeted Google Jobs listings for specific roles in the US, cleans the data, removes duplicates, and standardizes each job into a clear record with fields like job title, company, link, and source. This creates a reliable, structured pipeline of opportunities instead of a noisy, ad hoc search process.

From there, the system behaves like a lightweight job CRM. It checks an existing Google Sheet to avoid re adding the same roles, only writes truly new jobs with a default "New" status, and sends me a daily email summary so I know exactly which roles to prioritize that day. For each new job, an AI agent generates a tailored cover letter using the job description and my resume, and saves it as a separate Google Doc in a dedicated folder. As a result, I turned a manual, repetitive workflow into an automated funnel with clear tracking, reduced context switching, and faster time from discovery to first application.

Technologies

n8n, Google Cloud APIs (Sheets, Drive, Gmail), SerpAPI, OpenRouter

StratusAI

Description

StratusAI is a real time network threat detection product that I designed to turn raw packet data into clear, actionable security signals for security teams. Many security and SIEM tools rely heavily on syslog data, and after doing market research I realized that incorporating deep packet inspection can drastically increase threat detection quality. StratusAI ingests live traffic, groups it into flows to cut down noise, and uses TLS fingerprinting and anomaly detection to flag suspicious behavior such as scanning, beaconing, or data exfiltration, shifting teams from reactive log chasing to proactive insight.

On top of this engine, I built a dashboard that focuses on fast sense making for security analysts. The interface surfaces real time trends in bandwidth and anomaly levels, highlights critical alerts with context, and visualizes traffic on a globe so analysts can quickly see where threats are coming from and where they are going. Instead of exposing the underlying models and tooling, the product packages them into a simple experience that helps users quickly answer three questions: what is happening right now, what is risky, and where should I act first.

This project is still in progress as I continue refining detection models and expanding dashboard features.

Technologies

Python (Scapy, Pandas, Torch, Watchdog), PyTorch for neural networks, JA3 for TLS fingerprinting

Anomaly Detector

Description

Anomaly_Detector is a modern web application that leverages AI to analyze log files and detect anomalies in real-time, making complex system monitoring accessible to everyone. Built with React 18 and TypeScript, the platform is powered by Cisco's Foundation-Sec-8B model - an 8-billion parameter AI specifically trained on enterprise network data and security logs.

This foundation model understands network infrastructure patterns and can identify subtle anomalies that indicate security breaches, system failures, or performance issues, The application integrates Hugging Face Transformers to translate technical findings into human-readable explanations, essentially converting cryptic error codes into actionable insights that anyone can understand.

The platform supports multiple file formats including JSON, CSV, XML, Syslog, and plain text, processing them in real-time with sub-second results. Users simply drag and drop log files into the interface, where Cisco's AI analyzes the data for unusual patterns while Hugging Face models generate user-friendly explanations. All processing happens securely in memory without data storage.

Technologies

React + Typescript, Cisco's Foundation-Sec-8B model

Personal Accountant

Description

I designed a lightweight personal expense tracking assistant that lives inside Telegram and behaves like a simple, always available finance copilot. Instead of manually updating a spreadsheet, I can just message the bot with what I spent, and the workflow parses the message, captures the amount, category, date, and optional notes, then logs everything into Google Sheets in a structured way. The goal was to reduce friction in expense capture so that tracking becomes a natural part of daily behavior, not a separate task I have to remember.

On the product side, I focused on making the experience feel smart but predictable. I integrated Google APIs so the system updates in real time, iterated on prompts so the agent can respond in natural language and ask clarifying questions when my input is vague, and added small quality of life features like automatically converting expenses from INR to USD using the latest rates. The result is a simple but reliable workflow that turns a chat interface into a personal accountant, and it has given me clear ideas on how similar agentic patterns can be used to automate other everyday tasks.

Technologies

n8n, Google Cloud APIs(sheets, drive), Telegram Bot

Resume reviewer

Description

I wanted to build something that makes resume writing a little less overwhelming. The goal was to create a tool that feels more like a helpful assistant than a formal review process, and it has been rewarding to see how quickly it can provide actionable insights to improve resumes. Many of us know the struggle of tailoring a resume for each job application, so I decided to create a Telegram bot that could review resumes in a simple, interactive way. The idea was to give users instant, role-specific feedback on their resumes without making the process feel heavy or complicated.

To make this work, I used n8n as the backbone of the workflow and connected it with OpenAI's GPT 4.1 mini for the analysis. The bot first checks whether you've uploaded a file or just text. If it's a file, the content gets extracted through the "Extract from file" node, then passed to the AI for role-based review. I also added a simple Memory node so the bot can handle longer context smoothly. Once the analysis is complete, the feedback is sent back instantly on Telegram, making the experience feel seamless.

Technologies

n8n, Telegram Bot

Crisis Intelligence Web App

Description

A real-time global natural events visualization tool leveraging NASA's EONET API to monitor wildfires, volcanoes, ice formations, and severe storms. The application displays this data on an interactive map for disaster awareness and research purposes.

Technical implementation utilizes Python with Streamlit for the interface and Folium for mapping. The system processes NASA EONET data through Pandas, stores it in SQLite, and employs a Logistic Regression model (scikit-learn) to assign priority scores to events based on predicted importance and risk levels.

Technologies

Python, SQLite, Scikit-learn, Streamlit Cloud, Joblib, Folium

Echoes of Time

Description

A multimodal web application developed at CalHacks 12.0 that pairs video content with AI-generated music. The system extracts video frames, analyzes them with Google Gemini 1.5 Flash to identify thematic and emotional elements, then generates a synchronized 30-second soundtrack using the Lyria-002 music model.

The platform includes explainable AI features that detail the reasoning behind musical choices based on visual analysis. Built with Node.js, Express.js, and deployed on Google Cloud Platform using Vertex AI APIs.

Technologies

Google Gemini 1.5 Flash, Google Lyria-002, Vertex AI API, Node.js, Express.js, Google Cloud Platform
