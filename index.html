Other Projects

AI-Powered Job Search Automation

Description

This project is an AI powered job search assistant that I designed to reduce the time and effort spent on finding and acting on relevant roles. Every morning at 9 AM, the workflow runs automatically, pulls fresh and targeted Google Jobs listings for specific roles in the US, cleans the data, removes duplicates, and standardizes each job into a clear record with fields like job title, company, link, and source. This creates a reliable, structured pipeline of opportunities instead of a noisy, ad hoc search process.

From there, the system behaves like a lightweight job CRM. It checks an existing Google Sheet to avoid re adding the same roles, only writes truly new jobs with a default "New" status, and sends me a daily email summary so I know exactly which roles to prioritize that day. For each new job, an AI agent generates a tailored cover letter using the job description and my resume, and saves it as a separate Google Doc in a dedicated folder. As a result, I turned a manual, repetitive workflow into an automated funnel with clear tracking, reduced context switching, and faster time from discovery to first application.

Technologies

n8n, Google Cloud APIs (Sheets, Drive, Gmail), SerpAPI, OpenRouter

Echoes of Time

Description

A multimodal web application developed at CalHacks 12.0 that pairs video content with AI-generated music. The system extracts video frames, analyzes them with Google Gemini 1.5 Flash to identify thematic and emotional elements, then generates a synchronized 30-second soundtrack using the Lyria-002 music model.

The platform includes explainable AI features that detail the reasoning behind musical choices based on visual analysis. Built with Node.js, Express.js, and deployed on Google Cloud Platform using Vertex AI APIs.

Technologies

Google Gemini 1.5 Flash, Google Lyria-002, Vertex AI API, Node.js, Express.js, Google Cloud Platform
